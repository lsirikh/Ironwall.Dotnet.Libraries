# 그룹 심볼 변환(회전/확대축소) — 시나리오 카탈로그 v6

- **작성일**: 2026-09-04
- **대상 기능**: 맵 편집 모드에서 드래그(러버밴드)로 심볼 다중 선택 → 선택 영역 중심 기준 회전 / 확대·축소
- **연관 분석**: [group-symbol-transform-scenario-analysis.md](../analyses/group-symbol-transform-scenario-analysis.md)
- **전량 로그**: [group-symbol-transform-simulation-log.md](group-symbol-transform-simulation-log.md) (5,255건)
- **시뮬레이터**: 스크래치패드 `gtsim` v4(제품 코드 무접촉, 결정론 — 난수·현재시각 미사용)

> **v4 개정 사유(적대 검증 L2 지적 — 중대)**: v3.1은 진리값(GT)과 후보 방식(M2E)이 **같은 함수**여서 "M2E 291/291 통과"가 자기참조 항등식이었다. v4는 ①진리값을 후보와 무관한 **구면 측지**로 독립 구현하고 **화면 메르카토르 강체**를 제2 진리값으로 병기 ②접평면을 곡률반경 M/N으로 정정(v3.1은 등장방형 근사라 실제 비강체) ③허용치를 지상 0.1m 단일 기준으로 통일(v3.1은 블록마다 0.5px/0.05m 혼용) ④뷰포트 필터를 판정에서 분리 ⑤실코드 선례인 **서브픽셀 보간 증분(M1sub)** 변형 추가. **결론이 뒤집혔다** — 아래 성적표 참조.

## 진리값 2종 (정본 선택 = GAP-13)

| 코드 | 정의 | 관점 |
|------|------|------|
| **GT-GEO** | 구면 대원 강체 회전/스케일(중심 기준 방위각 +θ, 거리 ×s) | 지면 실측 — 측량·설치 도면 관점 |
| **GT-SCREEN** | 메르카토르 픽셀 평면 강체 | 관제 운용자가 화면에서 보는 관점 |

두 진리값은 서로 다르며(메르카토르는 위도에 따라 y 스케일이 변함), **어느 쪽을 "정본"으로 삼느냐가 방식 선택을 좌우한다.**

## 후보 방식 5종

| 코드 | 방식 | 실코드 근거 |
|------|------|------------|
| M1 | 증분 — 매 스텝 `geo → 정수 화면px → 변환 → 정수px → geo` | `FromLatLngToLocal/FromLocalToLatLng`가 정수(GMapControl.cs:2771-2782) |
| **M1sub** | 증분 + **서브픽셀 보간**(정수 절단 회피) | `SubPixelGeo.Bilinear` 선례(MarkerEditAdorner.cs:753-764) |

| M2E | base 합성, 접평면(ENU, 곡률반경 정정) | — |
| M3 | 반례 — 위경도 평면 직접 회전 | 왜곡 정량화용 |

## ★ 방식별 성적 (회전 SIM-R, 각 432건)

| 방식 | vs GT-GEO(지면) | vs GT-SCREEN(화면) | 판정 |
|------|----------------|-------------------|------|
| M1 (정수픽셀 증분) | 30 / 402 실패 | 46 / 386 실패 | **배제** — 진리값 무관하게 최악 |
| **M1sub (서브픽셀 증분)** | **348** / 84 실패 | **432 / 0** | 유효 |
| **M2 (화면공간 합성)** | **348** / 84 실패 | **432 / 0** | **채택 권고** |
| M2E (접평면 합성) | 243 / 189 실패 | 249 / 183 실패 | **배제** — 양쪽 다 열위(v3.1 결론 철회) |
| M3 (위경도 평면) | 192 / 240 실패 | 195 / 237 실패 | **배제** |

- M2와 M1sub는 회전 단발에서 **수치적으로 동일**(같은 연산, 절단만 차이). 차이는 **누적**에서 드러난다.
- M2/M1sub의 GT-GEO 실패 84건은 전부 **범위 500m 이상**(5000m 72건 + 500m 12건) — 즉 사이트 규모(≤500m)에서는 두 진리값이 사실상 일치.
- **v3.1의 "ENU(M2E) 최적" 결론은 철회**한다. 정정된 접평면으로도 M2E는 두 진리값 모두에서 열위다.
