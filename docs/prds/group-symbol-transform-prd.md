## 1. 개요

### 목적
맵 편집 모드에서 러버밴드로 선택한 다수 심볼을 **하나의 강체처럼** 회전·확대·축소한다. 현장 실측 도면과 지도상 심볼 배치가 통째로 어긋났을 때(설치 도면 회전, 축척 보정) 심볼을 하나씩 옮기는 대신 그룹 단위로 정합시키는 것이 목적이다.

### 배경 및 동기
- 현재 그룹 편집은 **이동·삭제·잠금·가시성·ZOrder·속성 균일 적용**까지만 가능하다(MapViewModel.cs:1201~1420, :8163).
- 회전/스케일은 **단일 심볼에만** 존재(MarkerEditAdorner 핸들)하며, 그룹 경로는 4계층(어도너/서비스/VM/DB) 전부 부재.
- 단, **"전무"는 아니다** — 그룹 공통 속성창이 Bearing/Width/Height를 **전원 동일값으로** 일괄 쓰는 경로가 이미 있다(GMapPropertyBaseControl.cs:1038-1040). 본 기능은 그것과 다른 **"상대(피벗 기준) 변환"**이며, 두 경로의 관계 정의가 필수다(FR-12).

### 사용자 우려에 대한 답 ("확대하면 깨지지 않나")
**심볼은 안 깨진다.** 7계열 전부 Viewbox+Path 벡터라 확대 시 재래스터라이즈된다(CustomMarkerStyle.xaml:19). **오버레이 이미지만** 래스터이며, 원본 해상도를 넘어서면 블러가 발생한다(SIM-Q: 원본 2000px·실폭 500m를 z19에서 ×2 하면 화면/원본 2.11배). 다만 화질보다 심각한 문제가 따로 있다 — **이미지 축소 시 단위 오판으로 폭이 668km가 되는 결함**(FR-06).

## 3. 기술 설계

### 아키텍처 결정과 이유

| 결정 | 채택안 | 이유(근거) |
|------|--------|-----------|
| 변환 수학 공간 | **화면(메르카토르) 공간 + 서브픽셀** | v4 시뮬: 화면 진리값 432/432, 지면 진리값 348/432(실패는 전부 500m 초과). 어도너 박스·마우스 제스처와 좌표계 일치. 접평면(ENU)은 양쪽 다 열위로 **철회** |
| 누적 방식 | **base 스냅샷 + 1회 합성** | 증분은 720스텝에 523m 드리프트(SIM-A4381) |
| 스냅샷 키 | **Id 딕셔너리**(인덱스 배열 금지) | 기존 그룹 이동의 인덱스 페어링이 집합 변이 시 붕괴(D-6) |
| HUD 위치 | **편집 스트립** | 어도너 HitTestCore가 클릭 투과(D-7), 적대검증 L4가 핸들 대안도 동일 실패 확인 |
| 계열 처리 | **타입별 분기** | 단일 RenderTransform은 라인 미회전, 단일 모델회전은 Bearing 규약 충돌(SIM-C) |
| 영속 | **배치 트랜잭션 + 부분 UPDATE** | 부분 커밋 영구 불일치(D-4), 전체행 UPDATE는 Category 오염 이력 |

### 주요 컴포넌트 (신규)
- `Services/GroupTransformSession.cs` — 스냅샷·누적 파라미터·미리보기·커밋·무효화
- `Utils/GroupTransformMath.cs` — 순수 함수(회전/스케일 합성, 피벗 산출) · 헤드리스 테스트 대상
- `GMapControls/GroupTransformHudControl.cs` + `Themes/GroupTransformHudStyle.xaml` — 편집 스트립 HUD
- `GMapDbSymbolService.BatchUpdateTransformAsync` — 트랜잭션 배치 영속
- `Services/Undo/Commands/GroupTransformCommand.cs` — 매크로 자식 커맨드

### 데이터 모델
**스키마 변경 없음**(GAP-15에서 MapId 신설을 택하면 별도 마이그레이션). 기존 컬럼만 사용: `Symbols(Latitude, Longitude, Bearing, Width, Height)`, `LinePoints`, `PidsGroupPoints`, `Images(Left/Top/Right/Bottom, Rotation, Width, Height)`.

## 4. 범위

### In Scope
러버밴드로 선택된 **점 심볼·라인·구역(PidsGroup)**의 그룹 회전/확대축소, 미리보기, 배치 영속, 1매크로 Undo, 세션 가드, HUD.

### Out of Scope
- **오버레이 이미지 마커 포함 여부는 GAP-10 결정 대기** — 결정 전까지 현행(러버밴드 제외) 유지
- 3D 하우징·지도 회전(별도 PRD)
- MapId 스코프 도입(GAP-15)
- 서버 푸시·낙관적 동시성(현행 last-write-wins 유지, 리스크만 문서화)
