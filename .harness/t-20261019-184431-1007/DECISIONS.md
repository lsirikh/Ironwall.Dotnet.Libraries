# DECISIONS

## 1. 지시의 가설(회전 정의 불일치)과 실제 원인이 달랐다 — 무엇을 고칠까
- options: (a) 회전 정의를 다시 손본다 · (b) 증거대로 실제 원인 둘(장면 밖 오버레이를 허공에 그림 · 뷰어 enuOf 구 반지름 0.3 % 차)을 고친다
- chosen: (b). 회전 정의(GIS · map-3d · 뷰어 yaw · 높이표)는 건드리지 않음
- why: 캡처는 옛 장면 5e0a01(로그 18:42:18~20, 썸네일 일치). 회전 장면 GLB 지형 모서리는 측지선 진실값과 0.004 m 안. 남은 어긋남은 enuOf(전 장면 공통 1.4 m)와 장면 밖 오버레이뿐
- effect: 회전 수식 코드는 그대로. 다르게 하려면 map3d.patch 의 해당 부분만 빼면 된다

## 2. 장면 영역 밖 오버레이 처리
- options: 숨김 · 지형 가장자리 높이로 그대로 그림(예전) · 반투명 · 여유 거리(예: 20 m) 두고 숨김
- chosen: 지형이 덮는 네모(회전 영역이면 회전 사각형, 아니면 bbox)와 조금도 겹치지 않는 항목만 숨김(여유 0). 선 · 면 · 이미지는 걸치면 보임, 위치 모를 항목 · 추적 타겟은 예전대로
- why: 캡처의 "허공에 뜬" 모습이 바로 이것. 회전 장면은 감싸는 bbox 모서리(회전 사각형 밖)도 지형이 없다
- effect: 3D 에서 장면 밖 장비 · 선 · 사진은 안 보인다(2D 로 나가면 그대로). 바꾸려면 overlay3d.refreshVisibility 의 `&& n.inArea` 를 빼거나 itemInArea 에 여유를 준다

## 3. 뷰어 위경도 ↔ 장면 좌표 길이(enuOf · lonLatOf)
- options: 구(R=6378137, 예전) 유지 · WGS84 곡률 반지름(지형 · RotRect 와 같은 길이)
- chosen: WGS84 곡률 반지름 — 회전 없는 옛 장면에도 적용(오버레이 · 카메라 · 커서 위경도)
- why: 지형은 타원체 ENU 로 굽는다. 구로 셈하면 0.24~0.31 % 짧아 안양 장면 모서리에서 1.37 m, 높이표가 0.49 m 엉뚱한 자리를 읽었다
- effect: 모든 장면에서 오버레이 · 2D↔3D 카메라 자리가 지형과 cm 안으로 맞는다. 줌 환산(metersPerPixel, Web Mercator)은 구 그대로. 되돌리려면 camsync.degLen 을 구 식으로

## 4. 기존 시험 rotated_check.mjs 의 rect() 도우미 수정
- options: 그대로 두고 새 시험만 추가 · 도우미를 RotRect 와 같은 타원체 식으로
- chosen: 도우미 수정(4줄) — 주석은 "RotRect 와 같은 식"인데 실제로는 구라서, enuOf(구)와 같은 가정을 공유해 0.3 % 어긋남을 못 잡던 바로 그 원인
- why: enuOf 를 바로잡으면 이 도우미만 틀린 값이 된다(시험 약화가 아니라 기준값 정정, 허용 오차는 그대로 1e-9)
- effect: 없음(시험만)

## 5. 이미 만든 회전 장면(f366a1) 다시 굽기
- options: 다시 굽기 · 메타 보정 · 그대로
- chosen: 그대로 — 고친 것은 뷰어(JS)뿐. 같은 요청으로 새 폴더에 다시 구워 보니 지형 x/z 가 원본과 0.0 m 차(같은 장면)
- why: 굽기 쪽 수식은 맞았다
- effect: map-3d 에 패치만 적용하면 기존 장면도 맞는다(GIS · WebView2 캐시가 옛 JS 를 쥐고 있으면 새로 고침 필요)

## 6. GIS 쪽 사각형 시험 허용 오차(화면 시늉)
- options: 0.3 m · 화면 1 px
- chosen: 화면 1 px(줌 17 ≈ 0.95 m), 크기 0.5 %
- why: Web Mercator 는 타원체에서 남북 · 동서 축척이 0.43 %(M/N) 달라, 돌아간 화면의 직사각형은 땅에선 살짝 비뚠 네모다. 영역은 땅의 직사각형(2D 테두리 = 3D 지형)으로 두므로 그린 러버밴드와는 1 px 안에서만 같다(실측 최대 0.93 m, −45°)
- effect: 없음(시험 기준). 러버밴드와 완전히 같게 하려면 영역을 평행사변형으로 바꿔야 해 범위 밖
